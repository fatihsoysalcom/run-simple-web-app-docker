# Run Simple Web App Docker

This example demonstrates how to package and run a simple Python Flask web application inside a Docker container. It dynamically creates the necessary application files and Dockerfile, then builds a Docker image and launches a container. This showcases Docker's ability to provide consistent and portable environments for applications.

## Language

`bash`

## How to Run

1. Ensure Docker is installed.
2. Save the code as `run_docker_example.sh` and make it executable: `chmod +x run_docker_example.sh`.
3. Run the script: `./run_docker_example.sh`. Access the app at `http://localhost:8080`. Press `Ctrl+C` to clean up.
